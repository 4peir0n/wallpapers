# wallpapers · 4peir0n

Una selección personal de **fondos de pantalla en 4K**.

## Galería

Visita la galería: **https://4peir0n.github.io/wallpapers**

La web es estática (HTML + CSS + JS): la lista de fondos se genera
localmente (`list.js`) y las miniaturas se sirven desde `thumbs/`, así que
no depende de ninguna API de GitHub.

## Estructura

```
images/     Fondos en 4K originales (lado mayor ≥ 3840 px) para el visor
thumbs/     Miniaturas WebP ligeras para la rejilla
list.js     Lista de fondos (generada automáticamente)
index.html  Página principal
styles.css  Estilos
images.js   Lógica de galería (lista, filtro, lightbox)
```
